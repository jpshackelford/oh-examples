# Dad joke about an animal

Tell a single, family-friendly dad joke about the animal named in
**$ARGUMENTS**.

## Instructions

1. Read the animal from the arguments: **$ARGUMENTS**. If it is empty, ask the
   user for their favorite animal and wait for their answer.
2. Tell exactly one short, groan-worthy, family-friendly dad joke (a pun is
   ideal) about that animal.
3. Keep it to the setup and punchline — no preamble, no explanation.

## Examples

`/dad-joke:about duck`
`/dad-joke:about cat`
`/dad-joke:about llama`
